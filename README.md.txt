# Сервис онлайн-записи в салоны красоты

Проект — сервис онлайн-записи в салоны красоты. Пользователи системы: клиенты, которые ищут услуги, выбирают мастера и записываются на удобное время; мастера, которые смотрят своё расписание; владельцы салонов, которые управляют услугами, ценами и графиком сотрудников. По данным клиент выбирает мастера по отзывам и ценам, а владелец решает, какие услуги развивать и как распределить нагрузку между мастерами. Тему выбрала, потому что мне интересна разработка IT-сервисов для реального бизнеса, а запись на услуги понятна каждому. В полной модели 11 таблиц, две связи «многие ко многим» (роли пользователей и услуги мастеров), большая таблица-факт appointments, которая вырастет до 300 тысяч строк, и текстовые поля (описания услуг и салонов, отзывы), по которым можно искать. На первой неделе созданы три справочника: категории услуг, услуги и салоны.

## Источник данных

Салоны (названия, адреса, телефоны) взяты из 2GIS, Алматы. Цены на услуги взяты из вкладки «Цены» салона Zuhra hanum beauty в 2GIS; для услуги с диапазоном цены указана нижняя граница. Категории услуг составлены по типам услуг, которые встречаются в прайсах салонов.
